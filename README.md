# แบบฝึกหัดที่ 16: Vue.js โปรแกรมตัดเกรดและดึงราคาทองคำผ่าน API

โปรเจกต์นี้มี 2 หน้าในเว็บเดียว:
1. โปรแกรมตัดเกรดจากคะแนน 0–100
2. หน้าแสดงราคาทองคำไทย โดยดึงข้อมูลจาก API จริง

## สิ่งที่ต้องติดตั้ง
- Node.js เวอร์ชัน LTS
- Visual Studio Code

## วิธีเปิดโปรเจกต์
1. แตกไฟล์ ZIP
2. เปิด Visual Studio Code
3. เลือก `File > Open Folder...` แล้วเลือกโฟลเดอร์ `vue-gold-grade-homework`
4. เปิด Terminal ใน VS Code (`Terminal > New Terminal`)
5. พิมพ์คำสั่งติดตั้ง dependencies:

   ```bash
   npm install
   ```

6. เมื่อเสร็จแล้ว สั่งเปิดเว็บ:

   ```bash
   npm run dev
   ```

7. เปิด URL ที่ Terminal แสดงให้ (โดยทั่วไปคือ `http://localhost:5173`)
8. ทดสอบทั้งแท็บ “โปรแกรมตัดเกรด” และ “ราคาทองคำผ่าน API”

## ตรวจสอบก่อนส่ง
- ทดลองกรอกคะแนน เช่น 85, 72, 61, 50 และ 40
- เปิดแท็บราคาทองคำและตรวจว่ามีข้อมูลจาก API
- ถ้า API ไม่ตอบสนอง ให้ลองกด “ลองใหม่อีกครั้ง” หรือทดสอบใหม่ภายหลัง
- แคปหน้าจอทั้ง 2 แท็บตามที่อาจารย์กำหนด

## อัปโหลดขึ้น GitHub
1. สร้าง repository ใหม่บน GitHub
2. ตั้งชื่อ repository เช่น `vue-gold-grade-homework`
3. ถ้าใช้ GitHub Desktop ให้เลือก `Add an Existing Repository` แล้วเลือกโฟลเดอร์นี้
4. กด Commit to main แล้วกด Push origin
5. คัดลอกลิงก์ repository ไปส่งอาจารย์

## API ที่ใช้
`https://api.chnwt.dev/thai-gold-api/latest`

API นี้ให้ข้อมูลวันที่/เวลาประกาศ ราคาทองคำแท่ง และราคาทองรูปพรรณ ค่าราคาจะเปลี่ยนตามข้อมูลจากต้นทาง ไม่ได้กำหนดตัวเลขราคาไว้ตายตัวในหน้าเว็บ

## หมายเหตุ
- เกณฑ์ตัดเกรดในตัวอย่าง: A = 80–100, B = 70–79, C = 60–69, D = 50–59, F = 0–49
- หากอาจารย์ให้เกณฑ์อื่น ให้แก้ใน `src/App.vue` ตรงฟังก์ชัน `grade`
- โปรเจกต์นี้ใช้ Vue 3 และ Vite
